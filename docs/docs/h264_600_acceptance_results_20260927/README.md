# H264 600 kbps 채택 시험 결과 (2026-09-27)

## 결론

**H264 600 kbps 단독 설정은 현재 채택 보류**다.

전체 100회 집계에서는 mp4v 대비 p50 28.62%, p95 38.11% 단축됐지만, 고정 참조 영상 `kakao_20260914.mp4`에서 p50 19.78%, p95 19.00%로 두 지표 모두 20% 단축 기준에 미달했다. 다른 고정 참조 영상은 p50 30.47%, p95 25.54%로 통과했다.

인코딩 성공률, 프레임 디코딩, 지속 워커 재사용, 운영 `main.py` 생존, 임시 파일 정리 및 온도는 모두 정상이다. 실패 원인은 안정성이 아니라 지연시간 개선 폭이다.
