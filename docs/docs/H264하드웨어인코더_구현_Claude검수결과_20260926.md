# 1차 구현 검수 결과

Claude 판정은 **조건부 반려**였다.

MUST:

1. 부모 비정상 종료 시 고아 worker 방지 수단 추가
2. 검증 prototype과 달랐던 `is-live=false`, `filesink sync=false` 제거 후 실기 검증
3. 연속 실패 횟수와 롤백 권고 상태 파일 추가

SHOULD:

- raw 저장공간 사전 확인
- timeout 진단 출력 보존
- worker PID/출력 경로 로그
- 장시간/실기 검증

## 반영

- worker에 Linux `PR_SET_PDEATHSIG(SIGTERM)`과 부모 PID 경합 검사를 추가했다.
- 파이프라인을 검증본의 `is-live=true`, 기본 filesink 동작으로 복원했다.
- `/tmp/drone_clip_encoder_state.json`에 worker/job 수, 성공/실패, 연속 실패,
  2회 연속 실패 시 `rollback_recommended`를 원자 기록한다.
- raw 파일 생성 전 payload+64MiB 여유 공간을 검사한다.
- worker PID, 출력 경로, timeout 시 worker log tail을 기록한다.
- Jetson에서 실제 작업기 H264 MP4 생성과 `gst-discoverer-1.0` 판독 성공,
  부모 종료 후 자식 종료 검사 성공.

이 문서는 1차 결과와 조치 기록이다. 최종 판정은 별도 재검수 결과를 따른다.
