## 3. VadCLIP 이상탐지 → 트리거 → 업로드 → 이벤트 시나리오

- [ ] 카메라 앞에서 사람이 움직이며 "이상행동"으로 보일 동작(빠른 움직임, 다수 인원 등) 재현 → `logs/main.log`에 VadCLIP score 상승 확인
  - 참고: 현재 `ANOMALY_THRESHOLD=0.4073` (임시값, 재보정 안 됨) — 리허설 중 실제로 안 넘을 수 있음. 필요시 강제 트리거 방법을 아래 "대안"에서 선택

- [ ] 트리거 발생 시 `main.py` 로그에 "⚠️ 이상 감지 트리거 발생" 확인
- [ ] 영상 업로드(`upload_clip_sync`) 완료, 서버 응답 수신 로그 확인
- [ ] AI서버(`dae_ai_server`)가 분석 완료 후 이벤트 등록되는지 서버 로그로 확인: `docker logs dae_ai_server --tail 50`
- [ ] 관제 웹에서 이벤트/알림이 실제로 뜨는지 확인 (`AlertPanel`, 이력 페이지)
