## 실행기 안전장치

- 지정 엔드포인트와 다른 값은 즉시 중단한다.
- 실제 전송 확인 문자열이 다르면 즉시 중단한다.
- 한 프로세스는 한 코덱 요청만 처리한다.
- sync uploader 경로의 encode 함수와 `requests.post`를 계측해 인코딩과 요청 시간을 분리한다.
- 출력 파일은 삭제되기 전에 SHA-256과 ffprobe 정보를 수집한다.
- 응답 상태 코드, 헤더, 본문, JSON을 원시 결과에 기록한다.
- 실패 시 자동 재전송하지 않는다.
