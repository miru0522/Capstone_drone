4. 각 출력 파일의 존재/크기와 cleanup, H264 상태·경로, 운영 PID·로그 중첩, 메모리 계측이 올바른가?
5. import 전역, monkeypatch, cleanup, 스테이징 경로 때문에 실행 실패나 측정 왜곡이 생길 버그가 있는가?
6. main.py 실행 중 이 40회 저장영상 시험을 실행 승인할 수 있는가?
